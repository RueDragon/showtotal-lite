# Windows Quick Start

1. Download the Windows x64 exe and `.env.example` from the same Release.
2. Put the exe in a writable folder. Windows 10/11 x64 is required.
3. Copy `.env.example` to `.env`, or fill in the settings on first launch.
4. Enter your own HTTPS statistics API prefix, API key and optional team path.
5. Run the exe. No Node.js installation is needed.

Never share the populated `.env`. Send only the exe and blank example to others.
The current adapter requires the statistics endpoints documented in README.md.
A generic OpenAI-compatible /v1 endpoint is not sufficient.

The binary is unsigned. Verify SHA256SUMS.txt and download only from the official
GitHub Release. Unknown-publisher prompts may appear on Windows.

Source startup: install Node.js 22 LTS or newer, run `npm ci`, `npm test`, then
`npm start`. Build with `npm run dist`. Fork adapter.js for another API platform.
